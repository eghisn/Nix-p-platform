# Licensed Web Fonts

Place the licensed `.woff2` files for the current NIXP font stack here.

Available licensed filenames:

- `FoundersGroteskWeb-Light.woff2`
- `FoundersGroteskWeb-LightItalic.woff2`
- `FoundersGroteskWeb-Regular.woff2`
- `FoundersGroteskWeb-RegularItalic.woff2`
- `FoundersGroteskWeb-Medium.woff2`
- `FoundersGroteskWeb-MediumItalic.woff2`
- `FoundersGroteskWeb-Semibold.woff2`
- `FoundersGroteskWeb-SemiboldItalic.woff2`
- `FoundersGroteskWeb-Bold.woff2`
- `FoundersGroteskWeb-BoldItalic.woff2`

These files are loaded by the public/admin stylesheet through the `Founders Grotesk Web` family name. The legacy `Founder Grotesq` name remains in the fallback stack so older local/system installs do not break the layout while the WOFF2 files define the visitor-facing typography.
